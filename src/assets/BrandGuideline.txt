2. Logo Usage
Primary Logo
•	Full-color logo with icon + text (blue + orange) 
•	Use on white or light backgrounds 
Secondary Logo
•	Monochrome (white) for dark backgrounds 
Clear Space
•	Maintain padding equal to height of logo icon 
Do Not
•	Stretch or distort 
•	Change colors 
•	Place on busy backgrounds

Primary Colors

4. Typography
Headings
•	Font: Sans-serif (e.g., Poppins / Inter / Montserrat) 
•	Style: Bold, large, clean 
•	Example: 
o	H1: 40–48px 
o	H2: 28–32px 
Body Text
•	Font: Same family (Regular / Medium) 
•	Size: 14–16px 
•	Line height: 1.5–1.7 
Buttons
•	Uppercase or Title Case 
•	Medium weight
